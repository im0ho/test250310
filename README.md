## ✨ 핵심 기능 (완료 사안)

프로그램은 크게 세 가지 유기적인 핵심 기능군으로 나뉘어 사용자에게 독창적인 경험을 제공합니다.

### 🐣 펫 파트 (Desktop Pet)
* **드래그 앤 드롭 자유 배치**: 바탕화면 공간 내 어디든 마우스 드래그로 캐릭터를 집어 올려 자유롭게 놓아둘 수 있습니다.
* **생동감 넘치는 애니메이션**: 기본 공중부양 모션, 눈 깜빡임, 대화 시 말하는 소리에 맞추어 입을 움직이는 애니메이션(Mouth-opening sync)이 적용되어 있습니다.
* **애정 어린 상호작용**: 놀아주기(`Heart` 버튼) 교감을 통해 상태 게이지를 관리하고 Moni를 건강하게 돌볼 수 있습니다.
* **지능적 스크린 제어**: 마우스 포인터가 지나갈 때만 오버레이를 감지하고, 비작동 시 뒤편 창을 클릭할 수 있도록 세밀하게 제어된 가림막(Transparent Screen Guard) 환경을 지원합니다.

### 💬 채팅 파트 (AI Chat Engine)
* **구글 Gemini 인공지능 탑재**: 바탕화면 속 비서와 언제든 실시간 질문, 추천, 고민 상담 등 자연어로 대화할 수 있습니다.
* **유연한 디자인 모드**: 펫 머리 위의 직관적인 **'말풍선 인터페이스'**와 별도의 고해상도 **'대화 이력 패널'**을 동시 제공하여 상황에 맞게 소통할 수 있습니다.
* **컨텍스트 유지**: 유저와의 지속적인 대화 히스토리를 기억하고 이에 알맞은 지능형 피드백을 전달합니다.
* **수려한 반투명 테마**: 어두운 유리 재질 느낌(Glassmorphism)의 반투명 오버레이를 적용해 바탕화면의 심미성을 해치지 않고 조화를 이룹니다.

### 📅 캘린더 파트 (Schedule & Alarm System)
* **캘린더 관리**: 할일 계획이나 약속 일정을 월간 단위 달력 위에 쉽고 깔끔하게 기록, 등록 및 수정할 수 있습니다.
* **지능적 알람 (Alarm Clock)**: 지정한 일정 시간이 되면, 알람음을 재생하고 말풍선을 띄워 무슨 일정 시간이 되었는지 알려줍니다.
* **테마 컬러 맞춤 설정**: 사용자별 선호 디자인에 맞도록 캘린더의 중요 강조색 글꼴 색상 지정을 커스터마이징할 수 있습니다.
* **고정 제어 기능 (Window Lock)**: 일정 관리창을 원하는 자리에 잠구어 일상의 방해 요소가 되지 않도록 맞춤 변경합니다.

## ⚙️ 실행 및 빌드 가이드

프로그램을 로컬 환경에서 직접 실행하거나 인스톨러(.exe) 패키지로 변환하는 방법입니다.

### 1단계. 종속성 설치 (최초 1회 필수)
다운로드받은 폴더 경로에서 터미널(VS Code / PowerShell 등)을 열고 아래 명령어를 실행합니다.
```bash
npm install
```
* 폴더 내에 `node_modules` 디렉터리가 정상 개발/생성되면 성공입니다.

### 2단계. API 키 구성
서비스 이용을 위해 루트 경로에 있는 `.env` 또는 `.env.local` 파일 내에 구글 API 키를 작성해 줍니다.
```env
# .env.local
GEMINI_API_KEY=여러분의_구글_제미나이_API_키
```

### 3단계. 바탕화면 실행 (개발 모드)
터미널 창에 다음 명령어를 입력하여 바탕화면에 펫을 직접 상주시키며 실행할 수 있습니다.
```bash
npm run desktop
```

### 4단계. 설치형 실행 파일(.exe) 패키징
실제 간편한 설치형 파일로 제작하려면 아래 빌드 도구를 실행해 줍니다.
```bash
npm run dist:installer
```
* 빌드가 끝나면 **`release`** 폴더 내에 **`AI DeskPet Setup 0.0.0.exe`** 설치 파일이 자동 생성됩니다.
* *(권장: 쉘 빌드 에러가 발생하는 경우 터미널을 **"관리자 권한"**으로 부팅해 재시도해 보시기 바랍니다.)*
